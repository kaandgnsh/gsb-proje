# M11 — Masaüstü ve alt süreçlerde ağ yalıtımı

Durum: **Linux doğrulaması tamamlandı** (2026-11-15). Windows güvenli kapalı;
gerçek Windows doğrulaması bekliyor. M12 uygulanmadı.

## Başlangıç

M02 ve M10 raporları, ana planın M11 kapsamı, runtime süreç/env/istemci/ağ denetimi
ve masaüstü başlatıcısı incelendi. Referans: **729 geçti; 16 gerçek entegrasyon
seçilmedi; 239,93 sn**. M02'nin Unix soketi üzerinden DNS sızıntısı açık başlangıç
bulgusuydu; loopback ve `OLLAMA_NO_CLOUD=1` yeterli sayılmadı.

M02'deki tarihî 9B kalite sonuçları (3 geçti, 2 başarısız) bu aşamanın yeni kalite doğrulaması değildir.
Hedef 4B model indirilmedi. Windows GUI ve gerçek model kalite takımı doğrulanmadı.

## Uygulanan sınır

`lai_runtime.sandbox`: Linux bubblewrap + libseccomp; kurulum/model indirme ve
sistem firewall/servis ayarı değişikliği yapmaz.

1. Ayrı kullanıcı/ağ/PID/mount/IPC ad alanları; capability yok; yalnız özel lo.
   INET/INET6 çıkışının ana makine ağına veya host loopback'ine yolu yoktur.
2. Özel `/run`, `/tmp`, `/proc`, `/dev`; gerçek HOME yerine `/run/lai/home`, özel
   geçici alan `/run/lai/tmp`. Açık uygulama/model kökü korunur. Root salt okunur;
   yalnız DB/app dizinleri ve `--write-dir` hedefleri yazılır.
3. Yalnız Wayland bağlantısı filtre öncesi açılır; bağlı FD Qt'ye aktarılır.
   Yeni AF_UNIX dahil INET/INET6 dışı socket domainleri reddedilir. Aynı sınırdaki
   işçi iletişimi için private AF_UNIX socketpair açıktır. Host Unix resolver/proxy,
   D-Bus/portal ve abstract soketlere yeni bağlantı kurulamaz.
4. Filtre uygulama kodundan önce yüklenir, exec/fork/thread ile miras kalır.
   no_new_privs, user namespace kilidi ve setns/unshare/clone-namespace/mount/
   ptrace/process_vm/pidfd_getfd/io_uring engelleri kaçış yollarını kapatır.
   Compat ABI çalıştırması filtre tarafından kabul edilmez; doğrulanan ABI x86_64'tür.
5. Fazla FD'ler kapatılır, standart FD'lerde bağlı soket reddedilir. Proxy,
   yükleyici, özel Qt eklentisi ve oturum broker ortamları taşınmaz.
6. Masaüstü ana girişi Qt/DB açılmadan sınırı kurar. Kurulamıyorsa Türkçe eksik
   önkoşul/çözüm mesajı verir, değerlendirme açmaz. Kısayol hata terminalini gösterir.
   Ortam bayrağına ek olarak gerçek çekirdek/socket kontrolleri zorunludur.

Masaüstünün ayar ekranından yalnız uygulamanın kendi runtime'ı başlatılıp
durdurulur. Yerel analiz de bu yöneticiyi kullanır. Kendi model deposu/loopback
portu kullanılır; sistem portu 11434 yasağı korunur. Kapanış sahiplik kontrolüyle
kendi sürecini kapatır; üst süreç kaybında PID namespace/bubblewrap çocukları kapatır.

[Kalıcı güvenlik kapsamı ve güven ilişkileri](../security.md): Wayland görüntü
sunucusu, yerel dosya/terminal I/O ve açık dosya aktarımı güvenilen sınırlardır.
Kullanıcının seçtiği klasörü başka bir programın buluta eşitlemesi, uzak/FUSE dosya
sistemi, kötü niyetli compositor veya değiştirilen kaynak kodu bu süreç ağ filtresinin
vaadi değildir. Yerel/eşitlenmeyen disk gerekir. Tüm bilgisayarı yalıttığı iddia edilmez.
Python API'sini dışarıdan çağırmak otomatik sandbox değildir; masaüstü otomatik,
diğer CLI işlemleri aşağıdaki ortak wrapper ile korunur.

## Kontrollü ağ kabul testi

Laboratuvarın kendisi de geçici user/mount/net/PID namespace'indedir. Dış tarafın
tek arayüzü lo'dur; `198.18.0.1` ve `2001:db8::1` kontrollü adresleri eklenir.
Gerçek internet veya kurum/sınav verisi kullanılmaz. TCP/UDP hedefleri ACK döner;
Unix ve loopback relay'leri veriyi kontrollü kolektöre gerçekten iletir.

Gerçek glibc `nss-resolve`, sentetik systemd-resolved varlink sunucusuna sorgu
yapar; bu sunucu da kolektöre iletir. `/run` ve nsswitch değişikliği yalnız dış
laboratuvarın mount namespace'indedir; gerçek çözümleyici/config değiştirilmez.

| Deneme yolu | Yalıtımsız | Yalnız netns | Tam sınır / alt süreç / sahte runtime |
|---|---|---|---|
| IPv4 TCP ve UDP | Ulaştı | Engelli | Engelli / engelli / engelli |
| IPv6 TCP ve UDP | Ulaştı | Engelli | Engelli / engelli / engelli |
| IPv4/IPv6, TCP/UDP 53 hedeflerine veri | Ulaştı | Engelli | Engelli / engelli / engelli |
| Host loopback proxy → kolektör | İletti | Engelli | Engelli / engelli / engelli |
| Dosya Unix proxy → kolektör | İletti | **Sızdı** | Engelli / engelli / engelli |
| Abstract Unix proxy | İletti | Engelli | Engelli / engelli / engelli |
| glibc → resolved Unix varlink → kolektör | Çözdü/iletti | **Sızdı** | Engelli / engelli / engelli |

**12/12 pozitif kontrol başarılı**. Tam korumada üç süreç bağlamının **12/12 yolu
engelli**; kolektöre yeni paket **0**. Başlangıçta kolektörde 16 istek görüldü.
M02 açığı namespace-only karşı kontrolünde yeniden üretildi; seccomp ile kapandı.

Ek gerçek kernel kontrolleri: AF_UNIX/NETLINK/PACKET/VSOCK reddi, setns/unshare
reddi, özel loopback ve private socketpair'in çalışması; devralınan socket FD'sinin
kapanması; namespace/önkoşul hatasında fallback olmaması; yalnız kendi süreç
ağacının kapanması ve yabancı sürecin çalışmaya devam etmesi.

Kanıt: [network-proof.json](assets/m11-linux/network-proof.json).
`netaudit.diagnostic` ve `doctor --network --pid` artık Unix uçlarını da gösterir;
çıktı açıkça **anlık örnek**, `enforcement_verified=false` der. Engelleme yerine
örnekleme, env bayrağı veya yalnız loopback istemci testi kullanılmadı.

## Çevrimdışı ve grafik akışlar

Tam sınır içinde, model olmadan sentetik belge aktarımı, tekil + üç toplu sonuç,
SQLite kayıt/yeniden açma, tekil dört biçim ve toplu CSV/XLSX/PDF arşivi çalıştı.

Gerçek Linux/Wayland oturumunda ve ardından ayrı D-Bus/geçici HOME kullanan sanal
Wayland compositor'ünde:

- Belge önizle/kaydet → eksik kritik bilgiyi yanıtla → sürüm seç → tekil sonuç aç.
- 20 katılımcılı toplu işi kes → pencereyi yeniden aç → sabit sürümle devam;
  20 benzersiz sonuç, mükerrer yok. Toplam 21 kayıt. Kısmi durumlar aynen korundu.
- PDF ve XLSX üret → uygulama içi salt okunur aç; 10 sayfa PDF çizimi ve Türkçe
  karakterler görüldü. Harici viewer/portal gerektirmez.
- Üretimdeki dosya seçiciyle Türkçe adlı sentetik dosya seçildi; normal masaüstü
  `main` girişi korunan bağlamda açılıp kapandı.

Sanal oturum `dbus-run-session -- /usr/bin/kwin_wayland --virtual
--no-global-shortcuts --no-lockscreen --no-kactivities --exit-with-session ...`
ile ayrı tutuldu; kullanıcının gerçek kısayol/panel/config dosyaları değiştirilmedi.
İlk yardımcı dosya seçimi denemesi seçim API'siyle takıldı ve başarı sayılmadı;
yardımcı üretim diyaloğunda gerçek metin alanı girdisine çevrildi, bütün akış yeniden geçti.

## Sahte bağlantı ve gerçek çıkarım ayrı

**Sahte runtime — teknik entegrasyon:** loopback sürüm/generate yanıtı, 12 dış
bağlantı denemesinin engellenmesi, port çakışmasında yabancı dinleyicinin korunması,
sahiplik ile durdurma ve yabancı sürecin korunması geçti. Model kalitesi ölçmez.

**Gerçek çalışma ortamı:** zaten kurulu 0.40.16 ikilisi önce boş özel model deposuyla
korunan sınırda başlatıldı; sürüm ve boş liste alındı, yalnız kendi süreç kapatıldı.
Ardından mevcut 9B ağırlığı salt okunur kaynaktan sha256 doğrulanarak geçici özel
depoya aktarıldı. Manifestler symlink olduğundan ilk dosya araması bunları kaçırmıştı;
`Path.is_file` ile genişletilmiş salt okunur arama kaynakları buldu.

CPU, 4 thread, 512 bağlam, en çok 16 token ve sentetik istek ile gerçek çıkarım:
**`TAMAM`, 4 token; 27,35 sn**. Yerel içe aktarma 29,74 sn. Kaynak ağırlığın boyutu
ve mtime'ı korundu; kopyanın özeti doğrulandı. Kaynak depo veya mevcut servis
ayarlarına yazılmadı, model indirilmedi. Bu **yerel çıkarım teknik duman testidir**;
Türkçe anlama/yorum/kural keşfi kalitesinin geçtiği anlamına gelmez.

[Gerçek çıkarım kanıtı](assets/m11-linux/real-inference.json).
Hedef 4B ve gerçek model kalite takımı doğrulanmadı; M02'nin tarihî kalite
başarısızlıkları gizlenmedi veya değiştirilmedi. Test sonrası yalnız bu görevin özel
model kopyası ve deneme alanları temizlendi; teslim kanıtları saklandı.

## Komutlar

```bash
# Normal masaüstü: yalıtım otomatik, başarısızlıkta değerlendirme açılmaz
PYTHONPATH=src .venv/bin/python -m lai.ui --db /veri/lai.db --write-dir /veri/raporlar

# Aynı sınırda CLI (dizin önceden var olmalı)
PYTHONPATH=src .venv/bin/python -m lai_runtime.sandbox --write-dir /veri -- .venv/bin/python -m lai.learning export --db /veri/lai.db --id 1 --format json --output /veri/sonuc.json

# Salt okunur anlık denetim; engelleme kanıtı değildir
PYTHONPATH=src .venv/bin/python -m lai_setup doctor --network --pid PID --json

# Gerçek kernel laboratuvarı + güvenli başlatma + çevrimdışı akışlar
.venv/bin/python -m pytest -q tests/security

# Tam teknik takım
.venv/bin/python -m pytest -q
```

Grafik harness örneği (Wayland oturumu gerekir):

```bash
PYTHONPATH=src:tests/support .venv/bin/python -m lai_runtime.sandbox --gui --write-dir /veri/kanit -- .venv/bin/python tests/security/run_checked.py /veri/kanit/kernel.json tests/ui/native_reporting.py --output /veri/kanit/raporlar
```

Önkoşullar: Linux kullanıcı/ağ/PID/mount namespace desteği ve yetkisi, ilgili
bayrakları destekleyen bubblewrap, libseccomp, grafik için Wayland soketi. Bu
ortamda bubblewrap 0.13.1 kullanıldı. Uygulama bunları kurmaz veya kernel ayarı
gevşetmez; yöneticiyle doğrulama mesajı verir. X11'e sessiz fallback yoktur.

## Teknik sonuçlar ve platformlar

Nihai: **747 geçti, 0 başarısız, 16 gerçek entegrasyon seçilmedi; 251,83 sn**.
747 = önceki 729 + 18 yeni güvenlik testi. İlk tam M11 çalışması da 745/745 geçti
(274,47 sn); özel HOME/runtime kökü düzeltmesi için iki test eklenip takım yenilendi.
Yeni modül/UI/test dosyalarında `ruff check`, tüm değişiklikte `git diff --check` temiz.

| Ortam / kategori | Sonuç |
|---|---|
| Linux x86_64, kernel 7.3.3, glibc 2.44, Python 3.14.7 | Tam teknik takım ve gerçek kernel laboratuvarı geçti |
| PySide6 6.12.0 offscreen | Teknik UI testleri geçti |
| Gerçek Wayland + ayrı D-Bus sanal Wayland | Korunan belge/tekil/toplu/rapor/dosya seçimi/giriş geçti |
| Mevcut gerçek çalışma ortamı + 9B, CPU | Korunan yerel çıkarım geçti; kalite takımı değildir |
| Önceki 16 gerçek entegrasyon testi | Bu takımda **seçilmedi**; manuel M11 çıkarımı bunların yerine sayılmadı |
| Windows GUI / ağ engelleme / named pipe broker | Gerçek ortam yok; **bekliyor**, normal başlangıç engellenir |
| Hedef 4B / gerçek model kalite takımı | **Bekliyor**, indirme yapılmadı |
| Linux X11 / ARM64 / macOS | Doğrulanmadı; Wayland doğrulaması bunlara kanıt değildir |

Windows'a WFP/firewall kuralı uygulanmadı. Uygulanan kontrol platform kapısı ve
Türkçe hatadır; Win32 seçimiyle DB açılmaması teknik birim testidir. M02'nin sahte
kernel32/Job Object testi gerçek Windows süreç veya ağ kanıtı sayılmadı.
M12 Windows doğrulama adımları ana plana bırakıldı; paketleme ve kurulum yapılmadı.
GPU yalıtım altında ayrıca doğrulanmadı; gerçek çıkarım CPU ile yapıldı.
